Scriptorium

julio de 2026

abrir Scriptorium · ver el código fuente

Descripción

Scriptorium es una aplicación web que desarrollé como un espacio personal de estudio. Reúne en una misma página distintas herramientas para organizar el trabajo cotidiano, registrar el progreso y conservar notas breves.

El proyecto busca recuperar la idea del escritorio de estudio como un lugar delimitado y silencioso. En lugar de presentar las herramientas como elementos aislados, todas forman parte de un mismo cuaderno digital.

Funciones

La aplicación incluye:

  • un temporizador Pomodoro;
  • una lista de tareas;
  • un calendario;
  • un espacio para notas;
  • un diario de estudio;
  • estadísticas de las sesiones realizadas;
  • un registro cronológico de actividad.

La información se guarda localmente en el navegador. No es necesario crear una cuenta ni conectarse a un servidor para utilizarla.

Diseño

El nombre del proyecto proviene de los espacios medievales dedicados a la lectura, la copia y la conservación de manuscritos. Esa referencia orientó tanto el nombre como la identidad visual de la aplicación.

La interfaz utiliza tonos oscuros, colores inspirados en el pergamino y una tipografía de carácter editorial. El objetivo no fue reproducir literalmente un escritorio antiguo, sino construir un ambiente sobrio que acompañara la concentración.

Un espacio de estudio no tiene que eliminar el paso del tiempo, sino hacerlo visible.

Implementación

Scriptorium está desarrollado como una aplicación web estática utilizando HTML, CSS y JavaScript. No emplea frameworks ni una base de datos externa.

Las distintas funciones están separadas en módulos de JavaScript para facilitar el mantenimiento del proyecto. La persistencia de tareas, notas, sesiones y registros se realiza mediante localStorage.

También puede instalarse como una aplicación web progresiva. Para ello incorpora un manifiesto y un service worker que permiten abrirla desde el dispositivo como una aplicación independiente.

Tecnologías

  • HTML para la estructura;
  • CSS para el diseño y la adaptación a distintas pantallas;
  • JavaScript para la lógica de las herramientas;
  • localStorage para la persistencia de los datos;
  • service worker y web manifest para las funciones de PWA;
  • GitHub Pages para la publicación.

Estado del proyecto

El proyecto se encuentra operativo. Puede utilizarse directamente desde el navegador y está pensado para seguir creciendo a medida que aparezcan nuevas necesidades de estudio y organización.
